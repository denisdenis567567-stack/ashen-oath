## Как запустить

Обновлён существующий Unity-проект:

`C:\Users\user\Documents\Codex\2026-11-03\battle-brothers-unity\ыыыы`

1. Откройте этот проект в Unity Hub (Unity **6000.3.27f2**).
2. Откройте сцену **Assets → Scenes → WorldMap** двойным щелчком.
3. Нажмите **Play**, затем перейдите в окно **Game**.

Чтобы запустить бой напрямую, откройте **Assets → Scenes → TestBattle**. Меню **Battle → Create Test Scene** также открывает эту сцену.
Для окна Game удобно выбрать соотношение сторон **16:9**. Интерфейс масштабируется вместе с окном.

Архив `AshenOath-Tactical-Unity.zip` содержит обновлённый проект без временных файлов Unity.
Его можно распаковать в новую папку и добавить через **Unity Hub → Add → Add project from disk**.

## Глобальная карта

- **ПКМ** по равнине задаёт точку назначения.
- Подведите курсор к краю окна игры, чтобы сдвинуть камеру. Колесо меняет масштаб вокруг курсора. Кнопка **Камера** открывает отдельные настройки скорости прокрутки и приближения.
- **Пауза**, **1×**, **2×** и **3×** управляют движением и игровыми часами. **Пробел** переключает паузу, **1–3** выбирают скорость.
- **Тестовый бой** запускает тактическую сцену. После победы или поражения нажмите **Продолжить путешествие**. Отряд вернётся в прежнюю точку, а карта откроется на паузе.

## Как менять здоровье, урон и другие числа — без кода

1. Остановите игру кнопкой **Play**.
2. Выберите **Battle → Open Battle Settings** в верхнем меню Unity.
   Либо выберите файл **Assets → Resources → BattleSettings** в окне Project.
3. Справа, в Inspector, измените подписанные поля.
4. Запустите **Тестовый бой** с глобальной карты или нажмите **Play** в сцене **TestBattle**.

Например, чтобы герой имел 50 здоровья и бил на 15: в разделе **Игрок** поставьте **Здоровье = 50**, **Урон = 15**.
Чтобы поменять карту, измените **Зерно генерации**. Одинаковое зерно и параметры дают одинаковое поле.
Меняйте именно файл BattleSettings, а не числа внутри скриптов. Настройки этого файла сохраняются между запусками.

## Управление

- **Tab** или кнопка **Инвентарь**: открыть окно персонажа. **Tab / Esc** закрывают его. Пока окно открыто, бой и управление камерой приостановлены.
- В окне нажмите **Изменить имя**, введите до 24 символов и нажмите **Сохранить** (или Enter). Имя сохраняется локально между запусками и отображается в HUD. **Отмена** отменяет редактирование; закрытие окна не сохраняет черновик.
- Инвентарь показывает текущие ХП, ОД, урон, стоимость действий и обзор. Пока не созданные характеристики обозначены прочерками. Шесть слотов экипировки и шесть ячеек сумки пока пустые: игровые предметы и их влияние на бой ещё не добавлены.
- **Перемещение / клавиша 1**: включить движение. ЛКМ по доступному гексу — пройти по самому дешёвому маршруту. Подсветка показывает доступные клетки, наведение — путь и суммарную стоимость.
- **Атака / клавиша 2**: сразу ударить ближайшую видимую цель в соседнем гексе. Сейчас враг один, выбирать цель не требуется. Без цели и без нужного количества ОД очки не списываются.
- **Завершить ход / Пробел**: передать ход ИИ. Затем управление автоматически возвращается игроку.
- **R**: новый бой с текущими настройками.
- Подведите курсор к краю окна игры, нажмите **WASD** или зажмите **среднюю кнопку мыши**, чтобы сдвинуть камеру.
- **Колесо** меняет масштаб вокруг курсора. **F** переносит камеру к бойцу, **G** показывает всю карту.
- Кнопка **Камера** внизу справа открывает настройки скорости прокрутки у краёв и зума. Эти настройки общие для боя и глобальной карты.

## Правила и обозначения

Поле состоит из **1024 гексов**, у каждого шесть соседей. Расстояния, атаки и видимость считаются по гексам.

| Объект | Как выглядит | Правило |
|---|---|---|
| Обычная земля | Коричневый гекс | Шаг 1 ОД |
| Возвышенность | Охристый гекс с треугольником | Подъём с низины 2 ОД; движение по верху и спуск 1 ОД |
| Болото | Зелёный гекс с полосками воды | Вход 2 ОД |
| Большой камень | Серый камень | Нельзя войти или пройти сквозь клетку |
| Дерево | Тёмно-зелёная ель | Нельзя войти или пройти сквозь клетку |
| Игрок | Голубая фигура на золотом гексе | Управляется вами |
| Враг | Красная фигура | Управляется ИИ |

В пределах 5 клеток видна вся местность. За пределами обзора неизведанные клетки почти чёрные, ранее увиденная местность затемнена. Враг скрывается сразу после выхода из обзора. Подсказки и подсветка не раскрывают неизведанные клетки. Двигайтесь к краю видимой области, чтобы открыть следующий участок.

На этой стадии деревья, камни и высота **не перекрывают обзор**: применяется радиус по расстоянию. Это отдельное от блокировки движения правило.

Игрок ходит первым. У каждого бойца собственный запас ОД, который восстанавливается в начале его хода. Нет промахов, защиты или случайного урона. При 0 ХП бой заканчивается. Для нового боя нажмите R.

ИИ знает положение игрока, обходит препятствия, учитывает дорогие поверхности, идёт к самой дешёвой доступной клетке рядом с игроком и атакует, пока хватает ОД. Если пути нет или оставшихся ОД не хватает на следующий шаг, заканчивает ход. Игрок не может действовать во время движения и хода ИИ.

В HUD видны ХП, урон и ОД обоих бойцов. Когда враг скрыт, его текущие ХП и ОД заменены знаком вопроса; максимальные характеристики остаются видны.

## Почему 32×32

В опубликованной декомпиляции шаблона равнины Battle Brothers метод `init` задаёт `MinX = 32` и `MinY = 32`. Это ориентир выбранного шаблона, а не утверждение, что все арены игры одинаковы. Код и графика Battle Brothers в этот проект не копировались.

Источник размера: https://github.com/ninkjin/Battle-Brothers-Scripts/blob/main/scripts/mapgen/templates/tactical/tactical_plains.nut

Описание гексов, высоты и тумана разработчиками: https://battlebrothersgame.com/tactical-combat-mechanics/
